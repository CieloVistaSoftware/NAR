# NAR

**Live site: https://cielovistasoftware.github.io/NAR/**

A critical examination of the New Apostolic Reformation's theology and practice — written from roughly 25 years of firsthand experience inside the wider charismatic movement, sourced and searchable.

Start with the [Introduction](https://cielovistasoftware.github.io/NAR/?page=introduction), then [The New Apostolic Reformation](https://cielovistasoftware.github.io/NAR/?page=nar) — the main article.

## What's here

- **Articles** — full-text searchable, `?page=articles`
- **Doc** — glossary, verified links for every person/organization named, sources, and a timeline, `?page=docs`
- **Issues** — corrections and bug reports, pulled live from this repo's GitHub Issues, `?page=issues`

## Running locally

```bash
npm install
npm start
```

Zero-build — no bundler, no compile step. Edit any file under `pages/` or `docs/` and reload.

Scaffolded with [create-wb-starter](https://github.com/CieloVistaSoftware/wb-starter).
